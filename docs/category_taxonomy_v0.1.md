# 기사 주제 표준분류 v0.1

> 목적: 언론사별 CMS 분류와 무관하게 기사 내용 자체를 일관된 기준으로 분류한다.
> 상태: 초안. 실제 수집 기사 샘플을 AI로 분류해 본 뒤 수정한다.

## 기본 원칙

- `category_original`: 언론사 원문 CMS 분류. 원형 그대로 보존하며 통계 기준으로 사용하지 않는다.
- `category_primary`: 1차 분류. 기사당 반드시 1개.
- `category_secondary`: 2차 분류. 기사당 반드시 1개.
- `category_tertiary`: 3차 분류. 필요한 경우에만 선택적으로 사용.
- `topic_tags`: 중복 가능한 세부 주제/기관/산업 태그.
- 분류는 등장인물이나 기관이 아니라 **기사의 중심 사건·쟁점·뉴스 가치**를 기준으로 한다.
- 지역성은 주제가 아니므로 `지역`을 1차 분류로 두지 않는다. 별도 `geographic_scope`, `region_tags`로 관리한다.
- [단독], 기획, 인터뷰 등 기사 형식은 주제 분류와 별도 변수로 관리한다.

## 경계 사례 우선 규칙

1. 정치인이 등장해도 **수사·기소·재판이 중심 사건이면 법조**.
2. 기업이 등장해도 **파업·교섭·임금·근로조건이 중심이면 노동**.
3. 정부 부처가 등장해도 정책의 실질 내용이 의료·교육·복지라면 원칙적으로 **사회 해당 분야**. 정책결정 과정 자체가 중심이면 정치·행정.
4. 부동산 기사에서 가격·시장·개발·사업성이 중심이면 **경제·산업 > 부동산·건설**. 주거권·피해·복지 문제가 중심이면 **사회**.
5. 기술기업 기사에서 실적·투자·사업전략이 중심이면 **경제·산업**, 기술 자체의 개발·성능·과학적 진전이 중심이면 **과학·IT**.
6. 범죄 발생 사실 자체가 중심이면 **사회 > 사건·사고**. 수사기관의 처분·영장·기소·재판이 중심이면 **법조**.
7. 지역 매체 기사라도 주제에 따라 정치·경제·사회 등으로 분류하고, 지역성은 별도 속성으로 기록한다.

## 3차 분류 사용안

3차 분류는 전 분야에 강제하지 않고, 분석 가치가 큰 분야에서만 사용한다.

예시:
- 법조 > 수사·기소 > 검찰·공소 / 중수청 / 특검 / 공수처
- 정치·행정 > 외교·안보 > 외교 / 남북관계 / 국방
- 경제·산업 > 기업·산업 > 반도체 / 자동차 / 배터리 / 조선
- 사회 > 보건·의료 > 의료제도 / 의약품 / 질병·감염병
- 노동 > 노사관계·쟁의 > 파업 / 단체교섭 / 노동쟁의

고정 3차 범주보다 `topic_tags`로 처리하는 것이 더 안정적인 분야는 태그를 우선한다.

## 별도 속성

```text
geographic_scope = NATIONAL | LOCAL | INTERNATIONAL
region_tags = ["서울", "경기", "울산", ...]
topic_tags = ["삼성전자", "파업", "반도체", ...]
classification_method = AI | MANUAL
classification_confidence = 0.00 ~ 1.00
taxonomy_version = "0.1"
classifier_version = 모델/프롬프트 버전
```

## AI 출력 형식 초안

```json
{
  "primary": "법조",
  "secondary": "수사·기소",
  "tertiary": "중수청",
  "topic_tags": ["대법원장", "업무추진비", "고발"],
  "geographic_scope": "NATIONAL",
  "region_tags": [],
  "confidence": 0.93,
  "reason_short": "기사의 중심 사건이 고발사건의 수사기관 배당이기 때문"
}
```

## 다음 테스트에서 확인할 것

- 1차 분류가 지나치게 넓거나 좁은지
- 법조/사회, 정치/사회, 경제/노동 경계에서 AI가 일관되게 판정하는지
- 2차 분류 중 실제 사용 빈도가 너무 낮은 범주가 있는지
- 3차 분류가 필요한 분야와 태그만으로 충분한 분야를 구분할 수 있는지
- confidence가 낮은 기사만 2차 판정 또는 수동 검토로 보낼 수 있는지
