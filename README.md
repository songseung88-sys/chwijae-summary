# 취재를 종합하면

한국 온라인 기사에서 **"취재를 종합하면"** 표현의 사용을 지속적으로 수집·분석하는 데이터 대시보드 프로젝트입니다.

## 운영 원칙

- NAVER API HUB: 후보 기사 발견
- 언론사 원문: 정식 분석 데이터 원천
- NAVER 뉴스 본문: 비교 검증 및 원문 파싱 실패 시 fallback
- 수집기는 Google Cloud Run Job에서 자동 실행
- 데이터는 Firestore에 저장
- API 키는 Google Secret Manager에만 저장하며 저장소에는 커밋하지 않음
- 웹 대시보드는 별도 정적 프론트엔드로 배포 예정

## 초기 수집 범위

- 메인 표현: `취재를 종합하면`
- 제목의 `[단독]` 동반 여부
- 동일 기사 본문 내부의 보조 표현
- 원문 메타데이터: 언론사, 기자, 입력/수정 시각, 원문 카테고리
- 원문 ↔ NAVER 전송본 비교
- 통신사 전재 의심 여부

> 이 저장소에는 API Secret/Key를 절대 커밋하지 않습니다.
