‘취재를 종합하면’ 연간 기사 수

10개 언론사 합계 · 연도별 검색 기사 수

데이터 불러오는 중

막대에 마우스를 올리거나, 키보드의 Tab 키로 연도를 선택하면 정확한 기사 수를 확인할 수 있습니다.

언론사별 ‘취재를 종합하면’ 사용 추이

한겨레 · 경향신문 · 조선일보 · 한국일보를 기본으로 표시합니다.

언론사 이름을 누르면 그래프에서 해당 언론사를 표시하거나 숨깁니다. 그래프의 연도에 마우스를 올리면 선택한 언론사들의 기사 수를 모두 확인할 수 있습니다.

출처·해석 안내 빅카인즈(BigKinds), 검색 표현 ‘취재를 종합하면’, 2016~2025년. 사용자가 직접 조사해 제공한 10개 언론사(경향신문·국민일보·동아일보·문화일보·서울신문·세계일보·조선일보·중앙일보·한겨레·한국일보)의 연도별 집계입니다. 검색 대상과 방식에 따라 결과가 달라질 수 있으며, 사용 빈도가 곧 취재의 질이나 언론사의 우수성을 뜻하지는 않습니다.
